# Git — шпаргалка

Git в этом конфиге разложен по нескольким инструментам; каждый закрывает свою часть.
В скобках — аналог в IDEA.

## Какой инструмент для чего

| Задача | Инструмент | Клавиши |
|---|---|---|
| что изменено в этом файле, по строкам | mini.diff — значки в signcolumn | `]h` / `[h`, `<leader>gd` |
| застейджить / откатить кусок файла | mini.diff | `ghgh` / `gHgh` |
| коммит, push, pull, rebase, stash, конфликты | lazygit | `<leader>gg` |
| история репозитория / ветки | lazygit, Telescope | `<leader>gl`, `<leader>gc` |
| найти изменённый файл и открыть | Telescope, neo-tree | `<leader>gs`, `<leader>pg` |
| переключить ветку | Telescope | `<leader>gb` |
| дифф с ревизией, лог с фильтрами (Java-проект) | intellij-lsp | `:IntellijGitDiff`, `:IntellijGitLog` |

Ветка и счётчик изменений `+ ~ -` — в lualine слева.

## mini.diff: ханки в текущем файле

Сравнивает буфер с индексом git (то, что уже застейджено) и рисует значки в signcolumn.
«Применить» ханк = застейджить его, «сбросить» = вернуть строки как в индексе.

| Клавиши | Что делает |
|---|---|
| `]h` / `[h` | следующий / предыдущий ханк (Ctrl-Alt-Shift-↓/↑) |
| `]H` / `[H` | последний / первый ханк |
| `<leader>gd` | оверлей: удалённые строки видны прямо в буфере (Show Diff inline) |
| `ghgh` | застейджить ханк под курсором |
| `gHgh` | откатить ханк под курсором (Rollback Lines) |
| `gh` / `gH` в visual | застейджить / откатить выделенные строки |
| `gh` + движение | застейджить диапазон: `ghip` — абзац, `ghG` — до конца файла |
| `dgh` / `ygh` | удалить / скопировать ханк — `gh` как текстовый объект |

Откат через `gH` — обычная правка буфера: передумал — `u`.

## lazygit (`<leader>gg`)

Полноценный git-клиент во всплывающем окне (Commit Ctrl-K, Git tool window Alt-9).
`<leader>gl` открывает его сразу на логе. Справка по клавишам текущей панели — `?`.

| Клавиши | Что делает |
|---|---|
| `1`…`5` | панели: статус, файлы, ветки, коммиты, stash |
| `[` / `]` | вкладки внутри панели (например, локальные ветки / remote / теги) |
| `/` | фильтр в текущем списке |
| `<Space>` | застейджить / убрать файл; `a` — все файлы |
| `<CR>` на файле | построчный стейджинг: `<Space>` — строка или ханк, `v` — диапазон |
| `d` | отменить изменения файла |
| `c` | коммит; `A` — amend последнего |
| `P` / `p` | push / pull |
| `n` в ветках | новая ветка; `<Space>` — checkout |
| `r` / `s` / `f` / `d` в коммитах | reword / squash / fixup / drop (интерактивный rebase) |
| `<C-j>` / `<C-k>` в коммитах | сдвинуть коммит вниз / вверх |
| `z` / `Z` | undo / redo последней git-операции (через reflog) |
| `q` | закрыть, вернуться в nvim |

## Telescope

| Клавиши | Что делает |
|---|---|
| `<leader>gs` | изменённые файлы с диффом в превью; `<Tab>` — stage / unstage |
| `<leader>gf` | файлы, которые отслеживает git |
| `<leader>gc` | коммиты репозитория; `<CR>` — checkout коммита (осторожно: detached HEAD) |
| `<leader>gb` | ветки; `<CR>` — checkout |
| `<leader>gt` | stash; `<CR>` — применить |

## neo-tree: вкладка Git (`<leader>pg`)

Дерево только изменённых файлов. `<CR>` / `l` — открыть.

| Клавиши | Что делает |
|---|---|
| `ga` / `gu` / `gt` | add / unstage / переключить stage |
| `A` | add всех |
| `gr` | откатить изменения файла |
| `gc` / `gp` / `gl` / `gg` | commit / push / pull / commit + push |
| `gU` | отменить последний коммит |

В обычном дереве файлов (`<leader>pv`) `]g` / `[g` прыгают по изменённым файлам.

## intellij-lsp (в Java/Kotlin-проекте)

| Команда | Что делает |
|---|---|
| `:IntellijGitStatus` | изменённые файлы; `j`/`k` показывают дифф каждого |
| `:IntellijGitDiff [rev]` | дифф текущего файла с индексом или ревизией в diff-режиме: `]c` / `[c` — по изменениям, `do` — забрать кусок (Compare with Revision) |
| `:IntellijGitLog` | лог: `/` — по сообщению, `a` — по автору, `f` — по пути, `r` — диапазон ревизий |
| `:IntellijGitBranches` | ветки; `<CR>` — checkout |

Подробнее — в [intellij-lsp.md](intellij-lsp.md#git).

## Встроенный diff-режим

Работает в любом дифф-окне: `:IntellijGitDiff`, `nvim -d a b`, `:diffsplit file`.

| Клавиши | Что делает |
|---|---|
| `]c` / `[c` | следующее / предыдущее изменение |
| `do` / `dp` | забрать кусок из другого окна / отдать в другое |
| `:diffupdate` | пересчитать дифф после правок |
| `:diffoff!` | выйти из diff-режима во всех окнах |
