# Neo-tree — шпаргалка

Под этот конфиг (`lua/plugins/neo-tree.lua`): дефолтные маппинги neo-tree v3 плюс свои правки
(`h` / `l`, без `<space>`). Полный список прямо в дереве — `?`.

## Открыть

| Клавиши | Что делает |
|---|---|
| `<leader>pv` | дерево файлов слева, показать / скрыть (Alt-1) |
| `<leader>pr` | показать текущий файл в дереве (Alt-F1) |
| `<leader>pb` | открытые буферы |
| `<leader>pg` | изменённые в git файлы |
| `<` / `>` | соседний источник: Files / Buffers / Git (вкладки в winbar) |

Текущий файл подсвечивается в дереве сам (`follow_current_file`), из `.gitignore` скрыто,
dotfiles видны. Последнее окно с деревом закрывается вместе с редактором.

## Ходьба по дереву

| Клавиши | Что делает |
|---|---|
| `j` / `k` | вниз / вверх |
| `l` / `<CR>` | открыть файл или раскрыть каталог |
| `h` | свернуть каталог |
| `C` / `z` | свернуть текущий / все узлы |
| `<C-s>` | быстрый прыжок к узлу по метке (глобальное сохранение здесь не работает) |
| `<BS>` | корень дерева — на уровень выше |
| `.` | сделать каталог под курсором корнем |
| `]g` / `[g` | к следующему / предыдущему изменённому в git файлу |
| `/` | нечёткий поиск по дереву; `D` — только по каталогам |
| `f` | фильтр по имени (применяется по `<CR>`), `<C-x>` — сбросить |
| `H` | показать / скрыть скрытые и gitignored |
| `o` + `n` `m` `s` `t` `g` `d` `c` | сортировка: имя / изменён / размер / тип / git / диагностики / создан |

## Открыть файл

| Клавиши | Что делает |
|---|---|
| `l` / `<CR>` | в текущем окне |
| `s` / `S` | в vsplit / split |
| `t` | в новой вкладке |
| `w` | выбрать окно |
| `P` | превью во всплывающем окне; `<C-f>` / `<C-b>` — прокрутка, `l` — фокус в превью |
| `<Esc>` | закрыть превью |

## Файловые операции

| Клавиши | Что делает |
|---|---|
| `a` | создать файл; каталог — если имя кончается на `/`, можно с путём `a/b/c.txt` |
| `A` | создать каталог |
| `r` / `b` | переименовать / переименовать без расширения |
| `c` / `m` | копировать / переместить (спросит путь) |
| `y` / `x` / `p` | скопировать / вырезать в буфер neo-tree / вставить |
| `d` | удалить; `T` — в корзину, `u` — отменить удаление в корзину |
| `i` | сведения о файле |
| `R` | обновить |
| `<Tab>` | отметить узел для групповой операции |

## Источники Buffers и Git

| Клавиши | Где | Что делает |
|---|---|---|
| `d` / `bd` | Buffers | закрыть буфер |
| `ga` / `gu` / `gt` | Git | add / unstage / переключить stage |
| `A` | Git | add всех |
| `gr` | Git | откатить изменения файла |
| `gc` / `gp` / `gl` / `gg` | Git | commit / push / pull / commit + push |
| `gU` | Git | отменить последний коммит |

`q` — закрыть дерево, `?` — справка.
