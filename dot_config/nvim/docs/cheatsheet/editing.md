# Редактирование — шпаргалка

Под этот конфиг: Neovim 0.12, `clipboard=unnamedplus`, автодополнение без плагинов
(`autocomplete` + LSP), mini.pairs, mini.diff. В скобках — аналог в IDEA.

## Грамматика команд

`[count] оператор движение-или-объект` — например `d2w`, `ci"`, `>ap`, `gUiw`.
Оператор дважды — на всю строку: `dd`, `cc`, `yy`, `>>`, `gcc`.

| Оператор | Что делает |
|---|---|
| `d` / `c` / `y` | удалить / заменить (удалить и в insert) / скопировать |
| `>` / `<` / `=` | сдвинуть вправо / влево / выровнять отступ |
| `gc` | закомментировать (Ctrl-/) |
| `gU` / `gu` / `g~` | в верхний / нижний регистр / переключить |
| `gq` | переформатировать по ширине |
| `!` | прогнать через внешнюю команду (`!ip sort`) |

`.` повторяет последнее изменение целиком — сочетать с `n`: `cw` → `n` → `.` → `n` → `.`

## Текстовые объекты

`i` — внутри, `a` — вместе с обрамлением/пробелами. Работают с любым оператором и в visual.

| Объект | Что выделяет |
|---|---|
| `iw` / `aw` | слово; `iW` / `aW` — до пробелов (`foo.bar()`) |
| `is` / `ip` | предложение / абзац |
| `i"` `i'` `` i` `` | содержимое строки в кавычках, курсор может быть до них на строке |
| `i(` `i[` `i{` `i<` | содержимое скобок; `ib` = `i(`, `iB` = `i{` |
| `it` / `at` | содержимое / весь XML/HTML-тег |
| `gh` | ханк mini.diff (`dgh` — удалить изменения, `ygh` — скопировать) |

Treesitter в visual (0.12, Ctrl-W / Ctrl-Shift-W в IDEA):

| Клавиши | Что делает |
|---|---|
| `an` | расширить выделение до родительского узла (повторять) |
| `in` | сузить до дочернего узла |
| `]n` / `[n` | выделить следующий / предыдущий соседний узел |

## Вставка и правка строк

| Клавиши | Что делает |
|---|---|
| `i` `a` / `I` `A` | insert до / после курсора; в начале / конце строки |
| `o` / `O` | новая строка ниже / выше |
| `]<Space>` / `[<Space>` | пустая строка ниже / выше, не входя в insert |
| `J` / `gJ` | склеить строки / без пробела (Ctrl-Shift-J) |
| `r<c>` / `R` | заменить символ / режим замены |
| `~` | переключить регистр символа |
| `<C-a>` / `<C-x>` | увеличить / уменьшить число под курсором; в visual `g<C-a>` — нумерация |
| `u` / `<C-r>` | undo / redo (undo переживает закрытие файла) |
| `:m +1` / `:m -2` | сдвинуть строку вниз / вверх (Ctrl-Shift-↓/↑) |

## Insert-режим

| Клавиши | Что делает |
|---|---|
| `<Tab>` / `<S-Tab>` | по пунктам меню дополнения; без меню — прыжок по сниппету |
| `<C-y>` | **принять** пункт — только он применяет импорты, text edits, сниппеты |
| `<C-e>` | закрыть меню без вставки |
| `<C-n>` / `<C-p>` | дополнение словами из буферов |
| `<C-x><C-f>` | дополнение путей файлов |
| `<C-s>` | подсказка сигнатуры (LSP) |
| `<C-r>{рег}` | вставить регистр (`<C-r>"`, `<C-r>0`, `<C-r>+`) |
| `<C-w>` / `<C-u>` | стереть слово / до начала строки |
| `<C-o>{cmd}` | одна normal-команда без выхода из insert (`<C-o>zz`) |
| `<C-t>` / `<C-d>` | сдвинуть строку вправо / влево |

Скобки и кавычки закрывает mini.pairs; `<BS>` на пустой паре удаляет обе.

## Регистры

`clipboard=unnamedplus`: `y`/`d`/`p` по умолчанию работают с системным буфером обмена.

| Регистр | Что в нём |
|---|---|
| `"` | последнее скопированное или удалённое |
| `"0` | последнее **скопированное** — не затирается удалением: `yiw`, потом `ciw<C-r>0` |
| `"1`…`"9` | история удалений строк |
| `"a`…`"z` | свои; `"Ayy` — дописать в `a` |
| `"_` | чёрная дыра: `"_d` удаляет, не трогая буфер обмена |
| `"+` | системный буфер обмена |
| `".` / `":` / `"/` | последний вставленный текст / команда / поиск |

| Клавиши | Что делает |
|---|---|
| `p` / `P` | вставить после / до курсора |
| `"0p` | вставить скопированное, даже если с тех пор что-то удалял |
| `:reg` | содержимое регистров; в normal `"` сразу показывает их в which-key |

## Макросы

| Клавиши | Что делает |
|---|---|
| `qa` … `q` | записать макрос в регистр `a` |
| `@a` / `@@` | выполнить `a` / последний выполненный |
| `5@a` | пять раз |
| `:'<,'>norm @a` | на каждой строке выделения |
| `Q` | повторить последний записанный макрос; в visual — на каждой строке |

Макрос — это просто регистр: `"ap` вставит его текстом, можно поправить и забрать
обратно `"ayy`.

## Visual

| Клавиши | Что делает |
|---|---|
| `v` / `V` / `<C-v>` | по символам / строкам / блок |
| `gv` | восстановить последнее выделение |
| `o` | прыгнуть на другой конец выделения |
| `<C-v>` … `I` / `A` → `<Esc>` | вставить текст во все строки блока (мультикурсор для столбца) |
| `<C-v>` … `$A` | дописать в конец строк разной длины |
| `*` / `#` | искать выделенный текст |
| `>` / `<` | сдвинуть, `gv` вернёт выделение для повтора |

## Поиск и замена

| Команда | Что делает |
|---|---|
| `/text`, `?text` | поиск вперёд / назад; `<Esc>` в normal снимает подсветку |
| `:s/old/new/` | первая замена в строке; `g` — все в строке |
| `:%s/old/new/gc` | по файлу с подтверждением (Ctrl-R) |
| `:'<,'>s/…` | в выделении (`:` из visual подставит диапазон сам) |
| `:%s//new/g` | пустой шаблон — последний поиск: сначала `*`, потом замена |
| `:%s/\v(\w+)_(\w+)/\2_\1/g` | `\v` — «very magic», группы без экранирования |
| `&` | повторить последнюю `:s` на текущей строке |
| `:g/pat/d` | удалить все строки с `pat`; `:v/pat/d` — без `pat` |
| `:g/pat/norm A;` | normal-команда на каждой найденной строке |
| `:sort u` | отсортировать и убрать дубли (в выделении — `:'<,'>sort`) |

`ignorecase` + `smartcase`: строчные буквы — без учёта регистра, есть заглавная — с учётом;
форсировать — `\c` / `\C`.

Замена по проекту — см. [windows.md](windows.md#замена-по-проекту).

## Фолды

| Клавиши | Что делает |
|---|---|
| `za` / `zo` / `zc` | переключить / открыть / закрыть фолд под курсором (Ctrl-.) |
| `zR` / `zM` | открыть / закрыть все (Ctrl-Shift-+/-) |
| `zj` / `zk` | к следующему / предыдущему фолду |
