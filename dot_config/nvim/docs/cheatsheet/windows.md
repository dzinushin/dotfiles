# Окна, буферы, вкладки, quickfix — шпаргалка

Под этот конфиг: `splitbelow` + `splitright` (новое окно — снизу и справа), свои маппинги из
`lua/config/keymaps.lua`. В скобках — аналог в IDEA.

Буфер — открытый файл в памяти, окно — вид на буфер, вкладка — набор окон.
Закрыть окно ≠ закрыть буфер: он остаётся в `:ls` и в `<leader>fb`.

## Буферы

| Клавиши | Что делает |
|---|---|
| `<leader>fb` | список буферов в Telescope; `d` — закрыть (Ctrl-E) |
| `]b` / `[b` | следующий / предыдущий; `3]b` — через три (Alt-→/←) |
| `]B` / `[B` | первый / последний |
| `<C-^>` | предыдущий буфер — переключатель туда-обратно |
| `<C-q>` | закрыть буфер (`:bd`) (Ctrl-F4) |
| `<leader>n` | новый пустой буфер |
| `:ls` / `:b <часть имени>` | список / перейти по имени (с `<Tab>`) |
| `:%bd \| e#` | закрыть все буферы, кроме текущего (Close Others) |

## Окна

| Клавиши | Что делает |
|---|---|
| `<leader>sv` / `<leader>sh` | разделить вертикально / горизонтально (Split Right / Down) |
| `<leader>si` / `<leader>sd` | высота окна +2 / −2 |
| `<C-w>h` `j` `k` `l` | в окно слева / снизу / сверху / справа |
| `<C-w>w` / `<C-w>p` | следующее / предыдущее окно |
| `<C-w>q` / `<C-w>o` | закрыть окно / закрыть все, кроме текущего (`:only`) |
| `<C-w>=` | выровнять размеры (после ресайза терминала) |
| `<C-w>_` / `<C-w>\|` | развернуть по высоте / ширине (Ctrl-Shift-F12) |
| `<C-w>H` `J` `K` `L` | переставить окно к краю: слева / снизу / сверху / справа |
| `<C-w>x` / `<C-w>r` | поменять с соседним / повернуть окна |
| `<C-w>T` | вынести окно в отдельную вкладку |
| `<C-w>d` | диагностика под курсором во всплывающем окне |
| `<C-w>v` / `<C-w>s` | то же, что `<leader>sv` / `<leader>sh` |

`<C-h>`/`<C-j>`/`<C-k>`/`<C-l>` в этом конфиге заняты под движения по строке и абзацам,
поэтому между окнами — только через `<C-w>`.

## Вкладки

| Клавиши | Что делает |
|---|---|
| `:tabnew` / `:tabnew %` | новая вкладка / с текущим файлом |
| `gt` / `gT` | следующая / предыдущая; `2gt` — вторая |
| `:tabclose` / `:tabonly` | закрыть вкладку / все, кроме текущей |
| `<C-t>` в Telescope | открыть результат в новой вкладке |

Вкладки удобны как «рабочие столы»: дифф (`:IntellijGitDiff` открывает свой), отладка,
отдельная задача.

## Quickfix и location list

Quickfix — общий список мест (ошибки сборки, результаты grep, ссылки); location list — то же,
но у окна свой. Наполняют их Telescope (`<C-q>`), `:grep`, `gO`, `:IntellijLspCompilationErrors`.

| Клавиши | Что делает |
|---|---|
| `]q` / `[q` | следующее / предыдущее место в quickfix (F4 по Find) |
| `]Q` / `[Q` | первое / последнее |
| `]<C-q>` / `[<C-q>` | следующий / предыдущий файл в quickfix |
| `]l` / `[l`, `]L` / `[L` | то же для location list |
| `:copen` / `:cclose` | окно quickfix (`<CR>` в нём — перейти) |
| `:lopen` / `:lclose` | окно location list |
| `:colder` / `:cnewer` | предыдущий / следующий список — quickfix хранит историю |
| `:cdo cmd` / `:cfdo cmd` | команда на каждом месте / один раз на каждый файл |

## Замена по проекту

Аналог Replace in Path (Ctrl-Shift-R):

1. `<leader>fg`, набрать запрос — Telescope live grep.
2. `<C-q>` — все результаты в quickfix (или `<Tab>` по нужным и `<M-q>`).
3. Замена на каждом месте и запись файлов:
   ```vim
   :cdo s/old/new/g | update
   ```
   Пофайлово и быстрее, если в файле много совпадений:
   ```vim
   :cfdo %s/old/new/ge | update
   ```
4. Откатить в файле — `u` в нём; в Java переименование символа надёжнее через `grn`.

## Терминал

| Команда | Что делает |
|---|---|
| `:term` / `:vert term` | терминал в текущем окне / в вертикальном сплите (Alt-F12) |
| `i` / `a` | начать ввод в терминал |
| `<C-\><C-n>` | вернуться в normal — скроллить, копировать, переключать окна |
| `<leader>gg` | lazygit во всплывающем окне |
