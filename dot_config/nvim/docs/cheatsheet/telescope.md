# Telescope — шпаргалка

Под этот конфиг (`lua/plugins/telescope.lua`): дефолтные маппинги Telescope плюс свои правки.
Полный список прямо в пикере — `<C-/>` в insert или `?` в normal.

## Открыть пикер

| Клавиши | Пикер |
|---|---|
| `<leader>ff` | файлы проекта, со скрытыми, без `.git/` (Ctrl-Shift-N) |
| `<leader>fr` | недавние файлы (Ctrl-E) |
| `<leader>fg` | live grep по проекту, со скрытыми (Ctrl-Shift-F) |
| `<leader>fb` | открытые буферы — стартует в normal, `d` закрывает буфер |
| `<leader>fh` | help tags |
| `<leader>ed` / `<leader>en` | файлы `~/dotfiles` / конфига nvim |
| `<leader>ec` | эти шпаргалки и docs/ (`q` закрывает открытую) |
| `<leader>gf` / `<leader>gs` | файлы в git / изменённые файлы |
| `<leader>gb` / `<leader>gc` / `<leader>gt` | ветки / коммиты / stash |
| `<leader>fe` | file browser |
| `:Telescope` | список всех пикеров (например `:Telescope lsp_references`, `:Telescope resume`) |

## Внутри пикера

Пикер открывается в insert: печатаешь запрос, `<Esc>` переводит в normal, `i` — обратно.

| Insert | Normal | Что делает |
|---|---|---|
| `<C-n>` / `<C-p>` | `j` / `k` | следующий / предыдущий результат |
| | `gg` / `G`, `H` `M` `L` | в начало / конец, верх / середина / низ списка |
| `<CR>` | `<CR>` | открыть |
| `<C-x>` / `<C-v>` / `<C-t>` | то же | открыть в split / vsplit / новой вкладке |
| `<C-u>` / `<C-d>` | то же | прокрутка превью вверх / вниз |
| `<PageUp>` / `<PageDown>` | то же | прокрутка списка результатов |
| `<Tab>` / `<S-Tab>` | то же | отметить результат (мультивыбор) |
| `<C-q>` | то же | все результаты — в quickfix |
| `<M-q>` | то же | отмеченные — в quickfix |
| `<C-r><C-w>` | | вставить слово, бывшее под курсором до открытия |
| `<C-c>` | `<Esc>` / `q` | закрыть |

После `<C-q>` по quickfix ходят `]q` / `[q`, список — `:copen`.

## File browser (`<leader>fe`)

| Insert | Normal | Что делает |
|---|---|---|
| `<A-c>` | `c` | создать файл; каталог — если имя кончается на `/` |
| `<S-CR>` | | создать из того, что набрано в промпте |
| `<A-r>` / `<A-m>` / `<A-y>` / `<A-d>` | `r` / `m` / `y` / `d` | переименовать / переместить / копировать / удалить |
| `<C-g>` / `<BS>` на пустом промпте | `g` | к родительскому каталогу |
| `<C-e>` / `<C-w>` | `e` / `w` | в `~` / в cwd |
| `<C-t>` | `t` | сделать текущий каталог cwd |
| `<C-h>` | `h` | показать / скрыть скрытые файлы |
| `<C-f>` | `f` | переключить режим: файлы / каталоги |
| `<C-o>` | `o` | открыть системным приложением |
| `<C-s>` | `s` | отметить все / снять отметку |
