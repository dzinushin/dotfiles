# Навигация по коду — шпаргалка

Под этот конфиг: Neovim 0.12, свои маппинги из `lua/config/keymaps.lua`, Telescope, neo-tree
и `intellij-lsp.nvim` для Java/Kotlin. В скобках — аналог в IDEA.

## LSP: переходы по коду

| Клавиши | Что делает |
|---|---|
| `gd` | к определению (Ctrl-B) |
| `grt` | к определению типа |
| `gri` | к реализациям (Ctrl-Alt-B) |
| `grr` | использования (Alt-F7); с intellij-lsp — окно с живым превью, `q` возвращает на место |
| `gO` | символы файла в location list (Ctrl-F12); через Telescope — `<leader>ls` |
| `K` | документация под курсором (Ctrl-Q) |
| `<C-s>` в insert | подсказка сигнатуры (Ctrl-P) |
| `grn` / `<leader>lr` | переименовать (Shift-F6) |
| `gra` / `<leader>la` | code actions; с intellij-lsp — intentions IDEA (Alt-Enter) |
| `<leader>lf` | форматировать буфер (Ctrl-Alt-L) |
| `]d` `[d` / `]g` `[g` | следующая/предыдущая ошибка (F2); `]g` сразу показывает всплывашку |

Только с intellij-lsp (Java/Kotlin):

| Клавиши | Что делает |
|---|---|
| `<leader>ts` / `<leader>tu` | подтипы / супертипы (Ctrl-H) |
| `<leader>ci` / `<leader>co` | входящие / исходящие вызовы (Ctrl-Alt-H) |
| `<leader>ws` | поиск символа по проекту (Ctrl-Alt-Shift-N) |
| `<leader>rr` / `<leader>rd` | запустить / отладить класс под курсором |
| `<leader>b` / `<leader>B` | точка останова / с условием |
| `<leader>dc` `dn` `di` `do` `dq` | continue, step over / into / out, stop |
| `<leader>de` / `<leader>dw` / `<leader>dv` | вычислить выражение / watch / панель отладки |

## Вернуться назад

| Клавиши | Что делает |
|---|---|
| `<C-o>` / `<C-i>` | назад / вперёд по истории прыжков (Ctrl-Alt-←/→) |
| `g;` / `g,` | по местам правок (Ctrl-Shift-Backspace) |
| `''` | к позиции до последнего прыжка |
| `<C-^>` | предыдущий буфер |
| `]b` `[b`, `]B` `[B` | следующий / предыдущий буфер, первый / последний |

## Файлы и поиск

| Клавиши | Что делает |
|---|---|
| `<leader>ff` | поиск файла (Ctrl-Shift-N) |
| `<leader>fr` | недавние файлы (Ctrl-E) |
| `<leader>fg` | grep по проекту (Ctrl-Shift-F) |
| `<leader>fb` | открытые буферы |
| `<leader>gf` / `<leader>gs` | файлы в git / изменённые файлы |
| `<leader>pv` / `<leader>pr` | дерево файлов / показать текущий файл в дереве (Alt-F1) |

## Внутри файла

| Клавиши | Что делает |
|---|---|
| `*` / `#` | следующее / предыдущее вхождение слова под курсором; `n` / `N` — повтор |
| `%` | к парной скобке |
| `[[` / `]]` | к началу предыдущего / следующего блока (в Java — примерно соседние методы и классы) |
| `<C-j>` / `<C-k>` | абзац вниз / вверх (`}` / `{`) |
| `<C-h>` / `<C-l>` | начало / конец строки (`^` / `$`) |
| `zz` | строку с курсором — в центр экрана |
| `<C-d>` / `<C-u>` | полэкрана вниз / вверх |
| `ma` / `'a` | поставить метку / вернуться к ней; заглавная (`mA`) работает между файлами, как закладки IDEA |
